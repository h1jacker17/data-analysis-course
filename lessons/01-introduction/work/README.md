## A. Разделитель CSV

Сравнение таблиц и объяснение: При чтении файла без указания разделителя Pandas может неверно считывать столбцы, если используется точка с запятой вместо запятой. В результате данные попадают в одну колонку. Указание параметра `sep` решает эту проблему.

## B. Частичное чтение

Размеры результатов, nrows, usecols и отличие от head: Параметр `nrows` ограничивает количество строк, которые физически считываются из файла на диске в оперативную память. Метод `head()` просто отображает первые несколько строк уже загруженной таблицы. `usecols` позволяет загрузить только нужные столбцы.

## C. Выбор столбцов

Типы результатов, изменение исходной таблицы и единицы суммы: При выборе одного столбца возвращается объект Series. При выборе списка столбцов возвращается DataFrame. Изменение исходной таблицы происходит, если использовать методы с параметром `inplace=True` или перезаписывать переменную. Суммы в HMDA указываются в тысячах долларов.

## D. Маленький пример

Условия и дроби одобрений и выдач: На небольшой выборке, например первых 50-100 строках мы можем вручную посчитать количество одобрений и разделить на общее число строк, чтобы убедиться, что логика расчета долей работает верно.
