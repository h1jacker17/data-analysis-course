## H3. Инструменты

Series и DataFrame, пример:  DataFrame — это двумерная таблица, состоящая из строк и столбцов, где каждый столбец может иметь свой тип данных. Series — это одномерный массив данных. Пример из работы: Объект `home_decisions` — это DataFrame. А когда мы выделили из него один столбец `home_decisions["action_taken"]` и сохранили в переменную `home_outcomes`, этот объект стал Series.
nrows и head, пример: nrows — это параметр функции чтения данных (например, `pd.read_csv()`). Он ограничивает количество строк, которые физически загружаются из файла на жесткий диск в оперативную память. head() — это метод объекта DataFrame, который просто показывает первые N строк уже загруженной таблицы, не меняя саму таблицу. Пример из работы: Мы могли бы загрузить только часть данных, написав `pd.read_csv(..., nrows=100)`. Но мы загрузили всё, а для просмотра первых строк использовали бы `home_decisions.head()`.
Метод и атрибут, пример: Метод — это функция, привязанная к объекту, которая выполняет какие-то действия. Для вызова метода всегда нужны круглые скобки. Атрибут — это свойство объекта, которое хранит какую-то информацию. Для доступа к нему скобки не нужны. Пример из работы: Метод: `home_outcomes.value_counts()` — мы вызываем метод, чтобы он посчитал сколько раз встречается код 1, 2, 3. Атрибут: `home_decisions.shape` — мы обращаемся к свойству, чтобы узнать количество строк и столбцов.
Ссылка на документацию и что удалось уточнить: В ходе работы мы использовали метод `value_counts()`. В официальной документации Pandas https://pandas.pydata.org/docs/reference/api/pandas.Series.value_counts.html я уточнил параметр `dropna`. По умолчанию он равен `True`, но в коде мы использовали `dropna=False`, чтобы убедиться, что в наших данных нет скрытых пропусков.
